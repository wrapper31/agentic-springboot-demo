# Designs

One file per requirement, written by the `architect` agent (`.claude/agents/architect.md`) as stage 1
of the [agent pipeline](../LESSON-agent-pipeline.md) and approved by a human before any code is written.

Naming: `issue-<number>-<short-slug>.md`. A design is part of the PR that implements it, so reviewers
can check the code against what was agreed.
